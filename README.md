# WorldGen / WorldSculpt AWS preparation

This workspace contains the deployment notes and repeatable scripts for the
`scenegen-gpu-dev` AWS instance. The GPU instance is intentionally kept stopped
until Session Manager access is available.

Start with:

- `docs/worldsculpt-a10g-profile.md`
- `scripts/bootstrap_worldsculpt_a10g.sh`
- `scripts/run_worldsculpt_geometry.sh`

No credentials or Hugging Face tokens are stored in this repository.
